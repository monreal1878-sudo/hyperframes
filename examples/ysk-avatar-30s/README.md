# @ysk_ai1 · говорящий аватар · 30 с

Вертикальный ролик 1080×1920 на русском, собранный в HyperFrames. Говорящая голова —
статичный аватар из скилла `video-cover-generator`, оживлённый прямо в композиции.

- **Сценарий** — по скиллу `reels-hook-scriptwriter`, см. [`SCRIPT.md`](SCRIPT.md).
- **Стиль** — бренд-гайд @ysk_ai1: тёплый графит `#0A0A0A → #171310`, оранжевый
  `#FF8A00 → #FFC24B`, немного фиолетового `#8B5CF6`, condensed grotesk капсом
  (Oswald), оранжевый рим-лайт по силуэту.
- **Аватар** — фон вырезан штатной `hyperframes remove-background`, рим-лайт «запечён»
  в `assets/avatar.png`.

## Как оживлён аватар

Всё в `index.html`, детерминированно и перематываемо (GSAP-таймлайн):

| Что           | Как                                                                                                                                                                                                |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Липсинк       | SVG-накладка рта в пиксельных координатах исходника; открытие `scaleY` берётся кадр за кадром из огибающей громкости озвучки (`ENV`, 30 fps). Между фразами накладка гаснет и видна родная улыбка. |
| Моргание      | Две SVG-«века» цвета кожи, закрываются сверху каждые 2.4–4.2 с (seeded PRNG).                                                                                                                      |
| Жизнь в кадре | Покачивание ±0.8°, «дыхание» 1.2 %, лёгкий кивок в такт речи, панч-ины камеры на битах.                                                                                                            |
| Субтитры      | Фразы до 3 слов, активное слово оранжевое, ключевые остаются золотыми.                                                                                                                             |
| Сцены         | 6 заголовков с градиентным wipe-переходом; «пропсы» над ладонью: код → плеер → чипы и правка значения → полароид PNG → LIVE → комментарий «КОД».                                                   |

## Озвучка

Встроенный `hyperframes tts` (Kokoro) не умеет русский, поэтому голос — Piper
`ru_RU-dmitri-medium` через sherpa-onnx (`tools/tts.py`). Тайминги слов оцениваются
по слогам и паузам внутри фразы (Whisper-модель в этом окружении была недоступна).

```bash
pip install sherpa-onnx soundfile numpy
# голоса: vits-piper-ru_RU-{dmitri,denis,ruslan}-medium.tar.bz2 → tools/voices/
python3 tools/tts.py tools/voices dmitri-medium 1.0 assets/narration.wav
mv assets/narration.json tools/narration.json && python3 tools/inject.py
```

Поменять текст — правь `tools/script.json` (второе поле — как произносить, например
«Клод» вместо Claude), перегенерируй озвучку и, если сдвинулись сцены, поправь массив
`B` и `data-start` клипов.
