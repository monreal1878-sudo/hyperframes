# @ysk_ai1 · говорящая голова + субтитры · 30 с · без звука

Минимальный ролик 1080×1920 в HyperFrames: на экране только аватар, субтитры и движение.
Голос не вшит — его можно записать отдельно (например, в ElevenLabs) по `voiceover.txt`.

- **Сценарий** — по скиллу `reels-hook-scriptwriter`: [`SCRIPT.md`](SCRIPT.md).
- **Шрифт и цвет** — из бренд-гайда @ysk_ai1: Oswald капсом, оранжевый `#FF8A00 → #FFC24B` на тёплом графите.
- **Анимация — приёмы HyperFrames:**
  - фразы — стиль `caption-highlight` из реестра: плашка проезжает за активным словом;
  - ключевые слова — стиль `caption-kinetic-slam`: одно слово на весь экран, вход по очереди сверху / слева / справа / из точки, тряска камеры, вспышка;
  - камера — новый план на каждой фразе (как джамп-каты), медленный наезд внутри плана, zoom-blur на склейке;
  - аватар — липсинк по ритму текста, моргание, покачивание, «дыхание»; зерно и виньетка из реестра.

## Тайминг без звука

Ритм субтитров задан «направляющей» озвучкой: текст прогнан через русский Piper TTS
(`tools/tts.py`), растянут до естественного темпа (`tools/timing.py`, ×1.16) и вшит
в `index.html` (`tools/inject.py`). Звук в ролик не попадает. Готовые субтитры — `subtitles.srt`.

### Подогнать под свою озвучку из ElevenLabs

Твой голос ляжет по таймингу иначе. Самый точный путь — снять тайминг с самой записи:

```bash
npx hyperframes transcribe voice.mp3 --model small --language ru   # → transcript.json
```

Дальше слова из `transcript.json` (`text/start/end`) кладутся в `tools/timing.json`
вместо направляющих, `python3 tools/inject.py` — и субтитры, удары и рот встают точно в голос.
Добавь `<audio src="voice.mp3" data-start="0" data-track-index="0" class="clip">` в композицию.
